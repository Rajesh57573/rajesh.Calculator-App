# 🧮 Calculator App

A responsive calculator built using **HTML, CSS, and JavaScript** with a modern UI and light/dark theme switching.

## ✨ Features
- ➕ Basic arithmetic operations
- 📊 Percentage calculation
- 🧹 Clear all (AC) and delete last character (DEL)
- 🌙 Light and dark mode
- 🎨 Modern UI with interactive hover effects
- 📱 Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Material Symbols
- Google Fonts (Poppins)
